# IDC 能源负荷预测小模型（纯前端时序预测 Demo）

面向数据中心机房能耗管理场景的预测演示：基于 30 天历史负荷数据，用 **Holt-Winters 三重指数平滑**（水平 + 趋势 + 季节分解）预测未来 24–72 小时功耗，并联动「峰谷电价 × 制冷削峰」给出节能调度估算。

打开方式：直接双击 `index.html` 即可（需联网加载 ECharts 图表库；数据生成本地完成，不依赖后端）。

## 核心功能

| 模块 | 说明 |
| --- | --- |
| 数据生成 | 30 天 × 30 分钟粒度机房总功耗（IT 基础负载 × 业务日/周因子 + 室外温度驱动的制冷负载 + 噪声 + 异常尖峰），可调温度耦合系数、噪声水平、尖峰事件 |
| 模型训练 | Holt-Winters 乘法季节；自动模式在验证集上网格搜索 α/β/γ 最小化 MAPE，手动模式可自行调 α |
| 预测输出 | 未来 24/48/72h 负荷曲线 + 95% 置信区间；季节周期可选 24h（日）或 168h（周） |
| 效果评估 | 训练集 MAPE、验证集 MAPE、RMSE、R²；与「昨日同时刻朴素基准」「移动平均」对比柱状图 |
| 节能调度 | 峰谷电价（可调）+ 预测削峰阈值（可调）→ 折算未来 24h 可节省费用 |
| 数据导出 | 一键导出全部时序数据 CSV（UTF-8 BOM，Excel 可直接打开） |

## 界面

- 顶栏指标卡：训练/验证 MAPE、RMSE、R²、24h 预测峰值、节能估算
- 主图：历史真实值 + 模型拟合 + 未来预测（置信带）
- 副图：学到的 24h 季节因子曲线、三种模型验证误差对比
- 控制面板：数据参数、模型参数、训练/生成/导出按钮，全部实时联动

## 技术要点（面试/汇报可讲）

1. 时序预测选型：负荷数据同时具有**趋势**与**日/周双周期**，Holt-Winters 三重指数平滑天然适配，比线性回归/移动平均更适合；
2. 参数寻优：网格搜索平滑系数，在验证集上以 MAPE 为目标，避免手动调参的随意性；
3. 置信区间：用训练残差标准差近似 95% 预测带，为制冷调度提供风险边界；
4. 业务闭环：预测 → 峰谷电价 → 制冷削峰 → 费用估算，对应数据中心 **PUE 优化与制冷负荷调优**。
